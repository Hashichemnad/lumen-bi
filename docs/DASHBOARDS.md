# Dashboards

**Dashboards → New dashboard** (Explorers and up). Changes save automatically while you edit; press
**Done** to see it as others will.

## Building

- **Add tile**: a saved chart (yours), a text note (headings, lists, bold, links), an image or a web page
  (https addresses only; some sites refuse to be shown inside other pages). New tiles go in the first free
  spot. Drag a tile by its grip, resize it from the corner; the settings button changes its title or
  content.
- **Tabs**: add with **+ Tab**, rename with the pencil (or double-click), delete with ×. Filters apply to
  every tab.
- **Add filter**: choose a dataset and field. Text fields offer *pick values* (with search), *pick one
  value* or *search text*; numbers a *range*; dates *presets* (today, last 7/30/90 days, this month, last 3
  or 12 months, this quarter, this year) or a custom range. If other datasets on the dashboard have a field
  with the same name, they are filtered too; you can choose another field or "do not filter" per dataset.
  You can set a starting value.
- **Parameters** of the charts' datasets appear as controls next to the filters.
- **Options**: let a click on a chart filter the others; let people view the rows behind charts; use your
  own phone layout.
- **Phone layout**: switch the editor to the phone view and arrange tiles for small screens. Until you do,
  phones show the tiles stacked in reading order.

## Using a dashboard

- Change filters in the row at the top; every chart updates. **Reset** goes back to the starting values.
- Click a mark (bar, point, cell, row): **Filter the other charts** (shown as a chip you can clear), **Drill
  down** (date levels and hierarchies; use ‹ on the tile to go back) or **View data** (the rows behind it).
- Tile menu (⋮): view data, export CSV (Explorers and up), save as image, open the chart in the builder
  (if it is yours).
- **Copy link** copies an address that opens the dashboard with the same filters, parameters and tab.
- ☆ adds it to your favourites, shown first on the home page.

## Sharing and security

The owner or an admin uses **Share**: everyone, people or groups, each with *can view* or *can edit*.
Viewers can never edit, whatever they are given. People with *edit* can change the layout, add their own
charts, filters and tabs; only the owner or an admin can share or delete it. Anyone who can open it can
make their own copy (Explorers and up).

People see the charts **through the dashboard**: they do not need access to the datasets, and
**row-level security applies to each person** — a manager of the Finance department sees Finance rows
only, on the same dashboard where an admin sees everything. Through a dashboard a viewer can only narrow
the charts (filters, chart clicks), set parameters, drill along dates and the dataset's hierarchies, and
view the rows (if allowed); they cannot run other queries on the data. Sharing changes are recorded in the
audit log.

A chart that is on a dashboard cannot be deleted until it is removed from the dashboards.
